Round 5 is a clean test: everything above uses only rounds 1–4, so the played games were never in the data. Each check compares the team's own average with that average adjusted for the opponent's defense.

The chips show the opponent's defense against each position, relative to the league (+% = allows more than average). For finished games, the line under each team shows the FPT its G / F / C actually scored, against the team's own average.

Season FPT × how soft the round 5 opponent is at the player's position (per-36 allowed ÷ league). Players with 15+ min and 2+ games. Actual is the round 5 FPT where the game is over (PIR, +10% for a win).

How it's calculated

  • Source: every player's game log from the EuroGuru API (the same FPT as the app), grouped by the opponent and the player's position (G/F/C).
  • Per 36 min is the fairer view: FPT allowed to a position ÷ minutes played at that position × 36. Per game is the raw total, which also depends on how many players of each position the opponents use.
  • Small sample: only games per team so far. It also reflects which opponents a team has faced. Treat it as a tiebreaker, not gospel. It gets more reliable each round.
  • Round 5 actuals come from EuroLeague's live boxscores (FPT = PIR, +10% of |PIR| for the winning team), matched to positions by name. One player didn't match (TyTy Washington Jr.), so his FPT is missing from his team's guard total.
  • Projection is a simple multiplier, not the EuroGuru model. It isn't a forecast; it shows the size of the matchup effect.
